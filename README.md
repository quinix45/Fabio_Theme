This is a repository that contains a theme for Quarto Reveal JS that I created. The theme also includes some additional useful features have also been added through custom Java Script. 

Theme demo: [https://quinix45.github.io/Fabio_Theme/Theme_tester.html#/title-slide](https://quinix45.github.io/Fabio_Theme/Theme_tester.html#/title-slide)


## Download Theme

You can download the theme and the supporting files by opening a terminal in the desired directory and running the following line:

```sh
curl -fsSL https://raw.githubusercontent.com/quinix45/Fabio_Theme/main/getTheme.sh | bash
```

The script will the necessary theme files and set up the skeleton for a presentation. [curl](https://curl.se/) must be installed on the system.
